# Brand

The neighborhood robot's look. The site uses whichever of these files exist; without them it shows the name in text.

| File | Used for | Size |
| --- | --- | --- |
| `logo.webp` | Top of the chat on the home page, centered | 720px wide |
| `mark.webp` | The small bird in page headers and the footer | 240px wide |
| `favicon.png` | Browser tab icon | 64×64 |
| `apple-touch-icon.png` | Phone home-screen icon | 180×180 |
| `icon-512.png` | Home-screen icon on Android, install prompts | 512×512 |
| `og.jpg` | The preview card when someone shares the link | 1200×630 |

Knowy Plover's logo: a robot named in honor of the western snowy plovers. Colors in the site are taken from it: cream `#fdf8ec`, ink `#322e2b`, amber `#e79d1b`, sky `#8fb6c7`, sand `#f8e6c8`, plover brown `#cdad8d`.

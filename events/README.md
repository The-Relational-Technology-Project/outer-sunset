# Events

One file per event a neighbor chose to make public, named `YYYY-MM-DD-slug.md`. Copy `_template.md`.

Live calendars are read directly from `sources.yml` (outersunset.today, sunsetboard.org) and don't need copying in. Put an event here when it isn't on those, or when a neighbor asks the agent to add it.

The agent opens a PR here with the label `event`. A steward merges.

# Proposals

Open asks from neighbors: a build day, a tool library, a question for stewards. One file each, `YYYY-MM-DD-slug.md`. Copy `_template.md`.

A proposal is not a commitment. It's a public note that someone wants this, so the next person who asks can find them. The agent opens a PR here with the label `proposal` after checking whether the thing already exists (see `resources.yml`). It also tells the proposer how many times the topic has come up in `log/questions.md`.

Status moves by PR: `open` → `has-a-host` → `happening` → `done` or `parked`.

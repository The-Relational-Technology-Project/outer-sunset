# What people here have shared

One file per thing someone knew and chose to give to the neighborhood: a memory, a piece of history, an answer to another person's question. Knowy drafts these; a steward reads each one before it is added. Knowy passes them on as one person's account ("a neighbor shared that..."), never as settled fact.

```yaml
title: The plum tree by the gate
question: Who planted the plum tree?     # when it answers a question someone asked
shared_by: a neighbor                    # how they asked to be credited
how_known: I was there
shared: 2026-01-10
license: CC BY 4.0
```

The body is what they said, in their words. Leave out other people's names and addresses.

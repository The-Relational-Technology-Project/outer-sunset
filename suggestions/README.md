# Suggestions

Sources neighbors suggested for Knowy to read: a doc, a spreadsheet, a site, a calendar, a feed. One file each, `YYYY-MM-DD-slug.md`, arriving through Knowy (in the chat or the form on the sources page) as a pull request labeled `source`, with an email to the stewards.

Knowy never reads these files to answer questions. They're the queue and the record: what was suggested, and what the stewards decided. Neighbors see each one's title and status on the sources page.

## Fields

```yaml
title: Parents' daycare list
type: spreadsheet        # doc | spreadsheet | calendar | feed | site | file
url: https://...         # or file: <name> (sent to the stewards by email, not stored here)
kept_by: Outer Dadas
ok_to_share: Not sure, please check
updates: Every week
suggested_by: a neighbor
suggested: 2026-11-06
status: new              # new | in progress | added | declined
decision: Added as a recs/ file after the group said yes   # one line, shown to neighbors
```

The steward-facing note on how to bring each kind in is in `STEWARDS.md`.

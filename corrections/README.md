# Corrections

Merged corrections, dated and attributed, so the agent prefers them over anything it fetched. One file each, `YYYY-MM-DD-slug.md`. Copy `_template.md`.

A correction says what the agent believed, where that came from, what's actually true, and how the neighbor knows. The agent opens a PR here with the label `correction`. When answering, it says "a neighbor corrected this on <date>".

A correction targets one fact. `target` is the source id and record id the agent showed, or a free-text description. `field` is what changed (hours, address, closed, name, other).
